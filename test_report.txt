CL-MEE unit-test report
=======================

The six unit tests in `tests/test_clmee_revision.py` passed in the author-provided
Windows CPython 3.13.15 x64 run (6/6) and were independently rerun for this
package build under CPython 3.13.5 (6/6).

Tests cover the budget-matched post-hoc ranking invariant, common runner-up
anchor handling, identity-control tie behavior, score-envelope and display
budget constraints, validation-weight checkpoint integrity, and zero-evidence
handling.

Run from this directory with:

  .venv\Scripts\python.exe -m unittest discover -s tests -v

The full experiment run and JSON/CSV/manuscript/PDF consistency checks are
performed by `RUN_ALL_TESTS_WINDOWS.bat`.
